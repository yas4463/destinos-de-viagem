Minha paleta de cores
🔹 Azul-profundo (#1C3D5A) – Primária
→ Usado para títulos e cabeçalhos, garantindo presença forte e profissional.

🔹 Cinza-azulado (#708090) – Secundária
→ Perfeito para textos secundários, descrições e legendas, mantendo uma leitura suave.

🔹 Verde-acinzentado (#A8C0B3) – Complementar
→ Pode ser usado para destaques sutis, como botões, ícones ou links interativos.

🔹 Azul-noite (#0D2538) – Escura
→ Excelente para fundos de seções, rodapés e elementos que precisam de profundidade.

🔹 Azul-neve (#E3F2FD) – Clara
→ Ideal para fundos principais, espaços de respiro e áreas brancas sem ser puro branco.
